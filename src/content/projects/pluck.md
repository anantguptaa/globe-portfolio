- Built an Android event-lottery application with Kotlin, Jetpack Compose and Firebase for managing high-demand community events.
- Implemented organizer workflows for removing non-responsive selected entrants and updating waitlist states.
- Added CSV export for accepted entrants, allowing organizers to download and review final enrollment data.
- Enhanced the chosen-entrants screen with organizer controls and an export action.
- Added UI tests for the My Events screen and helped maintain the project’s automated test suite.
- Collaborated with a six-person team using GitHub workflows, code reviews and iterative feature development.
